Deliberate boundaries

DecisionCurrent ruleReason
Database providerDeferredApplication code accepts a standard PostgreSQL URL; no provider SDK leaks into the API.
Health checksNo database queryRoutine monitoring must not wake a scale-to-zero database.
Production routingOne CloudFront domainStatic pages and /api/* share an origin, avoiding production CORS complexity.
Infrastructure executionOperator-driven PulumiPulumi bootstraps infrastructure; it is not embedded in application CI/CD.
TestsDevelopment dependencies onlyVitest, pytest, coverage, and Ruff are never included in deployed artifacts.

Reviewable commit sequence

  1. Move the existing Angular app into the monorepo layout.
  2. Upgrade the supported frontend and unit-test toolchain.
  3. Add the FastAPI/Lambda API and first PostgreSQL migration.
  4. Add guarded AWS infrastructure without deploying it.
  5. Connect the existing contact form to the API.
  6. Add packaging, root workflows, and architecture documentation.

Deployment gate

Do not run Pulumi until the real AWS account ID, Route 53 hosted zone, ACM certificate, and database decision are confirmed. The stack enforces the account and zone checks, but review is still required.
